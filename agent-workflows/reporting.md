# Evidence reports

Create a new Markdown file under `.agents/reports/` for each implementation, QA,
review, and release/DevOps activity. Reports are immutable: correct a report with a
new report rather than editing an existing one.

Each report names the worktree/branch, scope, changed areas or checks, result, known
limitations, and whether production was touched. Test reports distinguish checks that
ran from checks that require external staging or simulators.
