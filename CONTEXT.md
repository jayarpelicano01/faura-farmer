# Faura Farmer

Faura Farmer helps a person maintain a complete financial picture across online and device-only workspaces. This glossary records the financial terms shared by the web and mobile experiences.

## Language

**Local workspace**:
A device-only financial workspace with no signed-in owner, server ownership, or synchronization requirement.
_Avoid_: Offline account, guest account

**Portable backup**:
A versioned financial document that can move financial records between workspaces without authentication, destination ownership, or credentials.
_Avoid_: Account export, sync file

**Restore**:
An atomic, additive import of a portable backup into a destination workspace. A restore never replaces a destination record.
_Avoid_: Replace, overwrite, merge

**Hidden debt**:
A paid or written-off debt removed from normal debt lists while remaining part of the permanent financial ledger and debt totals.
_Avoid_: Deleted debt, archived debt
